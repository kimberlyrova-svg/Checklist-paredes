Historial local

Se muestran solo registros del usuario actual. Los registros permanecen en este navegador hasta que se eliminen los datos del sitio o dispositivo.

Cómo evitar perder registros

1. Descargue un respaldo JSON al terminar cada jornada y guárdelo fuera del celular.

2. No use modo incógnito ni borre los datos del navegador.

3. Para recuperar registros, utilice «Importar respaldo». La importación combina registros por identificador, sin borrar los existentes.

4. Para utilizar la página completamente sin conexión desde un enlace, primero debe publicarse por HTTPS e instalarse o abrirse con conexión para guardar sus archivos.

5. La sincronización multiusuario entre teléfonos se implementará en una fase posterior; esta versión no la realiza.

Usar el DNI como PIN no es seguro: quien conozca el DNI podría ingresar. El PIN local y el respaldo JSON no constituyen un sistema de seguridad empresarial. No use esta versión como repositorio central de datos sensibles.
